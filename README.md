# Plinth

Offline desktop audio player.

Main programming langauges: Tauri 2 + SvelteKit + Rust (rodio/symphonia).
Target platforms macOS + Linux.

## Installation

You will need to install [bun][bun-install] and [rust][rust-install]. Once you
have those programming language environments installed, you can build the
application by running the following commands:

```sh
bun install
bun run tauri dev
```
